# Настройки для владельца грибнаялавка.рф

Просьба направить домен **грибнаялавка.рф** и **www.грибнаялавка.рф** на сервер **82.146.42.213**.

Действующие DNS: ns1.jino.ru, ns2.jino.ru, ns3.jino.ru, ns4.jino.ru. Их менять не нужно — достаточно отредактировать записи в текущей панели DNS Jino:

| Имя | Тип | Значение |
| --- | --- | --- |
| @ | A | 82.146.42.213 |
| www | A | 82.146.42.213 |

Заменить прежние A-записи этих двух имён, чтобы старый IP 81.177.139.247 больше не использовался. Если у www уже есть CNAME на основной домен, его можно сохранить вместо отдельной A-записи. Не оставлять A и CNAME одновременно для www. Если для @ или www есть AAAA на другой сервер, убрать их: IPv6 для этого подключения не указан. MX, TXT и записи других поддоменов сохранить.

ASCII-имя домена: `xn--80aaabhc9augs4a8p.xn--p1ai`.

На целевом сервере уже подготовлено временное перенаправление на https://grib.info. После изменения DNS просьба сообщить об этом: проверим публичные ответы и завершим выпуск HTTPS-сертификата. Для DNS в Jino обновление зависит от TTL; мгновенное переключение у всех провайдеров не гарантируется.
