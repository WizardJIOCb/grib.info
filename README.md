# grib.info — МухоморыЧ

Статическая витрина грибной лавки в Челябинске. 33 продукта, 68 вариантов фасовки; поиск, категории, описание, корзина и подготовка заказа в Telegram продавца `@MuxomorURAL`.

## Запуск

Node.js 22 или новее, без установки зависимостей:

```sh
npm start
```

Открыть `http://127.0.0.1:4173`. Для Nginx публикуется только каталог `public/`.

## Содержание и происхождение

Источники: сохранённая пользователем 28.10.2026 страница сообщества «МухоморыЧ | Челябинск» и публичные публикации Telegram канала `t.me/MycoMarket_URAL`. Каталог сверён 28.10.2026 с общим прайсом от 21.10 (`https://t.me/MycoMarket_URAL/131`) и ассортиментной публикацией от 21.10 (`https://t.me/MycoMarket_URAL/130`).

В каталоге 33 продукта и 68 вариантов. Для 31 продукта есть опубликованные цены; тибетский кордицепс и Иван чай остаются по запросу из-за отсутствия однозначного сочетания фасовки и цены. Каталог не расширялся новыми товарами из Telegram: текущая сверка обновляет ранее перенесённые позиции. Цены записаны в `build-catalog.mjs`; ссылки на источники, дата сверки и изображения — в `enrich-catalog.mjs`.

У мёда разнотравья единица фасовки «1,4» не указана в источнике: это прямо отмечено. Для ежовика 300 г общий прайс даёт 2700 ₽, а отдельный пост `/121` — 2100 ₽. Сайт использует общий прайс 2700 ₽ и показывает расхождение в карточке, корзине и тексте заказа. Опубликованная цена не означает подтверждение наличия продавцом.

Карточки содержат фактическое описание формы и фасовки. Лечебные обещания и схемы употребления из постов не перенесены. 21 карточка использует изображения из предоставленного сообщества и его публичного Telegram канала; ссылка и пояснение о типе иллюстрации доступны в описании товара. Фотография ассортимента не выдается за точную упаковку отдельной позиции. Остальные карточки используют условные SVG. Источники новых файлов — `public/assets/image-sources.json`. Шрифт Manrope размещён локально; лицензия в `public/assets/OFL.txt`.

Редактировать данные удобно в `build-catalog.mjs`, затем выполнить:

```sh
node build-catalog.mjs
npm run check
```

## Заказ

Корзина хранит только идентификаторы товаров, фасовки и количество в localStorage. Ввод города и комментария остаётся в памяти страницы. Ссылка `https://t.me/MuxomorURAL?text=...` передаёт текст Telegram и заполняет черновик сообщения. Клиент самостоятельно отправляет сообщение продавцу. Сайт не сообщает об успешной отправке и не принимает оплату. Если Telegram не заполнил текст, доступны копирование и ручной просмотр заказа.

Контакты взяты из исходной страницы: `+7 982 275-85-22`, `+7 (351) 39-29-007`. Юридические реквизиты продавца в предоставленном файле не найдены; на странице условий указано запросить их до оплаты. Формы регистрации и backend заказов нет.

## Аналитика

На всех HTML страницах подключён счётчик Яндекс Метрики `113845435` через внешний `public/metrika.js` с настройками из предоставленного кода: `ssr`, `webvisor`, `clickmap`, `accurateTrackBounce`, `trackLinks`, `ecommerce: "dataLayer"`, URL и referrer. Само подключение `dataLayer` не отправляет события корзины или покупки. Резервный пиксель работает без JavaScript. Политика CSP в Nginx разрешает адреса Метрики и Вебвизора согласно официальной инструкции: https://yandex.ru/support/metrica/ru/code/install-counter-csp. Страница конфиденциальности описывает подключённую аналитику.

## Сервер

- IP: `82.146.42.213`.
- Каталог: `/var/www/grib.info/releases/<commit>/`.
- Активная версия: `/var/www/grib.info/current`.
- Виртуальный хост: `/etc/nginx/sites-available/grib.info.conf`.
- Шаблон HTTP: `deploy/grib.info.conf`.
- Выпуск HTTPS: `deploy/activate-https.sh`, только после готовности DNS.

DNS-зона должна содержать `A grib.info 82.146.42.213` и `A www.grib.info 82.146.42.213` (либо `CNAME www grib.info.`). Перед переключением NS сначала создать зону на выбранном DNS-хостинге и проверить ответы его авторитетных серверов. Не добавлять AAAA без настроенного IPv6 сайта. Перед сменой делегации проверить существующие MX/TXT и DNSSEC.

FirstVDS: у VDS `15501382` подключён бесплатный DNS для 10 доменов. После обращения №15016893 провайдер открыл штатный вход в DNSmanager через инструкцию VDS. 28.10.2026 создана зона `grib.info`: точные A-записи `@` и `www` на `82.146.42.213` с TTL 300, NS `ns1.firstvds.ru` и `ns2.firstvds.ru`. Оба авторитетных сервера проверены напрямую. Автоматические wildcard и MX-записи из шаблона исключены. Справочная копия зоны — `deploy/grib.info.zone`. Услуги DNS в NIC.ru не приобретались.

Делегация и HTTPS работают: 28.10.2026 подтверждён публичный ответ `https://grib.info/` HTTP 200 с ожидаемым содержимым. Одноразовая служба активации HTTPS завершилась успешно. Сертификат включает `grib.info` и `www.grib.info`, срок действия проверенного сертификата — до 26.01.2027. Стандартный `certbot.timer` обслуживает продление.

`deploy/grib-info-https-once.service` — ограниченный одноразовый шаг развёртывания: до 8 часов ожидает правильные A-записи для обоих имён минимум у двух из трёх публичных резолверов, затем один раз запускает выдачу сертификата. Это не периодическое обслуживание: служба не включена в автозапуск и после выполнения или ошибки останавливается. Скрипты размещаются вне webroot в `/var/www/grib.info/deploy/`. Стандартный `certbot.timer` обслуживает продление уже выданного сертификата.
