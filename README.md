# grib.info — МухоморыЧ

Статическая витрина грибной лавки в Челябинске. 33 продукта, 68 вариантов фасовки; поиск, категории, описание, корзина и подготовка заказа в Telegram продавца `@MuxomorURAL`.

## Запуск

Node.js 22 или новее, без установки зависимостей:

```sh
npm start
```

Открыть `http://127.0.0.1:4173`. Для Nginx публикуется только каталог `public/`.

## Содержание и происхождение

Источники: сохранённая пользователем 28.10.2026 страница сообщества «МухоморыЧ | Челябинск» (`m.vk.ru/muhomorural`) и публичное описание канала `t.me/MycoMarket_URAL`.

26 основных продуктов перенесены из верхней записи «Ассортимент и цены». Более ранние позиции выделены в категорию «Под заказ» с ценой по запросу. Число 33 относится к товарам, найденным в предоставленном файле, а не к проверке всего архива сообщества. При конфликте цен использован верхний прайс.

У мёда разнотравья единица фасовки «1,4» не указана в источнике: на сайте это прямо отмечено. Масло, капсулы, экстракты, тибетский кордицепс и Иван чай требуют подтверждения цены и наличия.

Карточки содержат фактическое описание формы и фасовки. Лечебные обещания и схемы употребления из постов не перенесены. Иллюстрации взяты из сохранённых пользователем материалов сообщества; условные изображения упаковки нарисованы SVG. Шрифт Manrope размещён локально; лицензия в `public/assets/OFL.txt`.

Редактировать данные удобно в `build-catalog.mjs`, затем выполнить:

```sh
node build-catalog.mjs
npm run check
```

## Заказ

Корзина хранит только идентификаторы товаров, фасовки и количество в localStorage. Ввод города и комментария остаётся в памяти страницы. Ссылка `https://t.me/MuxomorURAL?text=...` передаёт текст Telegram и заполняет черновик сообщения. Клиент самостоятельно отправляет сообщение продавцу. Сайт не сообщает об успешной отправке и не принимает оплату. Если Telegram не заполнил текст, доступны копирование и ручной просмотр заказа.

Контакты взяты из исходной страницы: `+7 982 275-85-22`, `+7 (351) 39-29-007`. Юридические реквизиты продавца в предоставленном файле не найдены; на странице условий указано запросить их до оплаты. Формы регистрации, backend заказов, аналитики и рекламных трекеров нет.

## Сервер

- IP: `82.146.42.213`.
- Каталог: `/var/www/grib.info/releases/<commit>/`.
- Активная версия: `/var/www/grib.info/current`.
- Виртуальный хост: `/etc/nginx/sites-available/grib.info.conf`.
- Шаблон HTTP: `deploy/grib.info.conf`.
- Выпуск HTTPS: `deploy/activate-https.sh`, только после готовности DNS.

DNS-зона должна содержать `A grib.info 82.146.42.213` и `A www.grib.info 82.146.42.213` (либо `CNAME www grib.info.`). Перед переключением NS сначала создать зону на выбранном DNS-хостинге и проверить ответы его авторитетных серверов. Не добавлять AAAA без настроенного IPv6 сайта. Перед сменой делегации проверить существующие MX/TXT и DNSSEC.

FirstVDS: у VDS `15501382` подтверждён бесплатный лимит 10 доменов, 9 мест свободно. На момент подготовки прямой вход в DNSmanager в инструкции сервера отсутствовал. До получения доступа делегацию на FirstVDS не менять. Услуги DNS в NIC.ru не приобретались.

## Проверки первой версии

Проверены 33 уникальных продукта и 68 вариантов, смена фасовок, итог корзины, увеличение/удаление, восстановление после перезагрузки, поиск/категории, пустое состояние, товары с ценой по запросу, описание товара, адрес и текст Telegram, мобильное меню, ширины 360/390/430/768/1440 px, 404 и недоступность приватных исходных файлов из webroot. Реальное сообщение продавцу при проверках не отправлялось.

Исходный HTML содержит элементы личного интерфейса пользователя. Он и снимки проверки находятся в игнорируемом `reference/` и не публикуются.
